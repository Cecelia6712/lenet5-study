# LeNet-5 Revisited: Which Design Choices Actually Matter?

> A faithfulness audit of LeCun, Bottou, Bengio & Haffner (1998) on MNIST.

**Status**: E01 (faithful reproduction) in progress.

## The question

The 1998 LeNet-5 paper reports 0.95% test error on MNIST and attributes
it to four idiosyncratic design choices: sparse C3 connections, trainable
summation pooling, fixed RBF output with MSE loss, and a diagonal
Levenberg-Marquardt optimizer. Modern "LeNet" tutorials drop almost all
of them and still report ≈1%.

**Which of these choices were load-bearing in 1998, and which are
historical artifacts?**
